# Tools

## Basic

1. BethINI to generate performant, mod-friendly `.ini` configurations.
2. Mod Organizer to manage plugins and assets.
3. LOOT to automagically sort plugins (manage dependencies).

## Advanced

1. SSEEdit to clean and flag plugins.
2. Wrye Bash to create a final "bashed" patch.
3. Synthesis to run specialized patchers.

## Specialized

1. BodySlide to (re)generate body and clothing meshes.
2. DynDOLOD to (re)generate distant LOD assets.
3. Pandora to (re)generate animation files.
4. ParallaxGen to (re)generate texture and mesh assets for Complex Materials and Physically Based Rendering (PBR).
