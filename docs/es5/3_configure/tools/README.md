# Tools

## Basic

1. BethINI to generate modern, mod-friendly `.ini` configurations.
2. Mod Organizer to manage both plugins and assets.
3. LOOT to order plugins.

## Advanced

1. SSEEdit to clean and flag plugins.
2. Wrye Bash to create a final plugin patch.
3. Synthesis

## Specialized

1. BodySlide to (re)generate clothing meshes to match modded body meshes.
2. DynDOLOD to (re)generate distant LOD assets for mods that do not include them.
3. Pandora
4. ParallaxGen
