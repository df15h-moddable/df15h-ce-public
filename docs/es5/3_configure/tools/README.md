# Tools

## Basic

- BethINI to generate performant, mod-friendly `.ini` configurations.
- Mod Organizer to manage plugins and assets.
- LOOT to automagically sort plugins (manage dependencies).

## Advanced

- SSEEdit to clean and flag plugins.
- Wrye Bash to create a final "bashed" patch.
- Synthesis to run specialized patchers.

## Specialized

- BodySlide to (re)generate body and clothing meshes.
- DynDOLOD to (re)generate distant LOD assets.
- Pandora to (re)generate animation files.
- ParallaxGen to (re)generate texture and mesh assets for Complex Materials and Physically Based Rendering (PBR).
